# Python Exercises

A collection of beginner-friendly Python practice exercises.

## Exercises

- **`test1.py`**: Circle Area Calculator — Calculates the area of a circle from user-entered radius.
- **`test2.py`**: Reverse Full Name — Accepts first and last name from user and prints them in reverse and original order.
- **`test3.py`**: List and Tuple Generator — Accepts comma-separated numbers and creates both a List and a Tuple.
- **`test4.py`**: Sequence Generator — Splits comma-delimited input into a list and converts it to a tuple.
- **`test5.py`**: List Indexing — Accesses elements from a list using indices.

## How to Run

```bash
python3 test1.py
python3 test2.py
python3 test3.py
python3 test4.py
python3 test5.py
```
